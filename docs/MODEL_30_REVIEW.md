# 30種類の動物識別モデルの検討（2026-10-25）

## 今回の境界

現在のCLIP、ラベル、しきい値、Worker、キャッシュ、撮影後の推論処理は変更していない。この文書は将来の比較案であり、30種類対応モデルを実装したという意味ではない。30種の正式リストは未確定。登録済みの観察16グループと、種識別のラベル数は異なるため、観察課題IDを種の正解ラベルとして流用しない。

## 候補

| 候補 | 公開モデルの仕様 | このアプリで必要な作業 |
| --- | --- | --- |
| 現行 Xenova/clip-vit-base-patch32 | Transformers.js対応ONNX、ゼロショット画像分類 | 現状を維持。30種にラベルを増やすだけでは精度保証にならない。候補集合が変わるため、しきい値も再評価が必要 |
| MobileNetV3 Small（第一候補） | timm/mobilenetv3_small_100.lamb_in1k、ImageNet-1k学習、224×224、約2.5Mパラメータ、0.1 GMAC | 正式30種の写真で追加学習し、対象外・判別困難な写真を含めて拒否判定を検証。ONNXへ書き出し、前処理・演算対応を確認 |
| EfficientNet-Lite0（比較候補） | timm/efficientnet_lite0.ra_in1k、ImageNet-1k学習、224×224、約4.7Mパラメータ、0.4 GMAC | 同じ学習・検証写真で比較し、精度向上が端末負荷の増加に見合うか測定 |

公開モデルはいずれも「京都市動物園の対象30種に学習済み」というものではない。第一候補は軽さを優先した設計上の選定であり、園内精度・iPhone速度を実測した結論ではない。パラメータ数や演算量はモデルカードの値であり、配布ファイル容量や実行時メモリとは別である。モデルのライセンスと、学習写真の利用条件も別々に確認する。

## 学習・採用に必要な条件

1. 和名・学名・種IDの30種リストを確定。ヤギ／ヒツジなどグループと種の対応を明示。
2. 利用可能な撮影写真を集める。正面・横・遠景・柵・逆光・部分的遮蔽を含める。人物、看板、空の展示、他種なども検証用に用意する。研究参加者の撮影写真を無断で学習に転用しない。
3. 連写や同じ個体・撮影セッションが学習用とテスト用へ混ざらない分割を作る。写真不足の種は未評価とする。
4. 種ごとの再現率、適合率、混同行列、対象外の誤受理率、手動選択へ戻る割合を確認する。softmaxの最大値だけを確実性と扱わず、保留基準を検証データで調整する。
5. 同一のiPhone Safariで初回取得量、初回／準備済み推論の中央値・p95、メモリ、オフライン再推論、カメラから描画までの経過時間を測る。推論処理はWorkerで行う。
6. ONNX Runtime WebのWASMを基準に演算互換性を検証。量子化は軽量化と精度の両方を比較して採否を決める。WebGPUは端末で確認できた場合のみ別途比較する。
7. 結果が揃ってから既存インターフェース経由で差し替える。現行モデルを削除したり、未対応種を自動確定したりしない。
