# 絵の自動送信（Googleドライブ集約）の設置手順

お客さんが保存した絵を、同意した端末から自動で Googleドライブに集める仕組みの
設置手順です。所要時間は約5分です。サーバーの常設は不要です
（Google Apps Script が受け口になります）。

## 1. Apps Script を作る

1. https://script.google.com を開き「新しいプロジェクト」
2. 最初から入っているコードを全部消して、リポジトリの `gas/Code.gs` の
   内容を貼り付ける
3. 先頭の `TOKEN = "zooketch-2026"` を、自分の好きな文字列に変える
   （アプリ側の設定と一致させる合言葉です）

## 2. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類は「ウェブアプリ」
3. 設定：
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押す。初回は権限の承認（ドライブとスプレッドシートへの
   アクセス許可）が求められるので許可する
5. 表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）
   をコピーする

## 3. アプリ側の設定

ズーケッチの設定画面 →「絵の自動送信（研究用）」で：

1. **送信先URL** に、2 でコピーした URL を貼る
2. **トークン** に、1 で決めた文字列を入れる
3. 同意チェックを ON にする（実際の利用時は、おうちの人の同意を得てから）

これで、その端末で絵を保存するたびに自動で送信されます。
電波がないときは端末に貯めておき、次にアプリを開いたときにまとめて送ります。

## 4. 届いた絵の確認

- Googleドライブに **「ズーケッチ提出」** フォルダができ、絵（PNG）と
  線データ（JSON）が入ります
- スプレッドシート **「ズーケッチ提出一覧」** に、受信日時・動物・課題・
  絵へのリンクが1行ずつ追記されます

## 注意

- コードを直したら「デプロイ」→「デプロイを管理」から **新しいバージョン** で
  再デプロイしてください（URL は変わりません）
- トークンは簡易的な合言葉です。URL とトークンは研究関係者の外に
  公開しないでください
- 写真と声メモは送信されません。送られるのは完成した絵（PNG）、線データ、
  動物名、課題名、日時、プロフィールID、気づいたこと（任意入力）だけです
