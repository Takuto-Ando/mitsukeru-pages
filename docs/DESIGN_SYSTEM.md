# カードを基本にした4画面

参照作品：[動物園で親子の学びを促すツール](https://student.redesigner.jp/portfolios/PFbf718c53a677d2027c72b1472808bbab)

2026-10-24、公開ポートフォリオの作品写真と使用方法の図をブラウザで目視確認しました。原版PDF・Figma・正式な色指定は未取得です。

## 読み取ったルール

- ターコイズ、コーラル、マスタードの単色枠とアイボリーの面。
- 濃い文字、短い問い、余白を確保したカードの表面。
- 目や特徴を強調した簡潔な動物表現。
- めくってイラストと短い解説が現れる構成。

元作品の画像・ロゴ・イラストはアプリへ転載していません。既存の独自SVGを使用し、名称はズーケッチのままです。

## 実装ルール

`src/styles/tokens.css` が色・文字サイズ・余白・角丸の唯一の基準です。色は作品写真からの目視による近似値で、原版の正確な値ではありません。

| トークン | 値 | 用途 |
| --- | --- | --- |
| color-teal | #75a99b | 撮影・解説、操作 |
| color-coral | #ca7d61 | 描画カード |
| color-mustard | #c4a052 | 比較カード、確認 |
| color-paper | #faf7ec | ページ |
| color-surface | #fffdf5 | カード面 |
| color-ink | #514638 | 本文 |
| radius-card | 8px | 共通カード |
| radius-control | 4px | ボタン・選択肢 |

`src/styles/cards.css` は4画面・保存一覧の共通組版です。旧CSSに色を上書きする方式ではなく、独立したスタイルへ置換しました。主操作は48px以上、描画ツールは44px以上のタッチ領域を確保します。

- 各画面は共通の活動カード・上部見出し片・余白を使用。
- 手順は「撮る／描く／比べる／知る」の短い日本語のみ。操作できない手順をボタンに見せません。
- 撮影は単色のカメラ枠と円形シャッター。モデル準備などは「撮影の設定」に格納。
- 描画は全身の空欄へ直接。SVG・Canvas・お手本は600×600の同じ座標。
- 完成時だけ短いカードの回転とフェード。重ね合わせは約0.8秒。浮遊・点滅・バウンス・紙吹雪は使用しません。
- 解説は完成した動物と短い文章。元の線は比較・保存一覧に保持。
- 写真・動物の判別に必要な自然色は保持。UIとSVGのグラデーション・ガラス表現・影は使用しません。
- prefers-reduced-motionでは演出を即時表示へ切り替え。

Figma移植時は、上記の意味ごとの変数とActivity card／Controls／Comparisonの構成を対応させてください。正式素材や色指定の取得前に、原作品に完全一致したとは扱いません。
