# ズーケッチ Figma v2 の照合と削除候補

## 照合した資料

2026年11月21日付の統合版指示に付属する実測画面順を使用した。現行Figmaの「プロトタイプ1」のフレーム名と、手元の書き出しに含まれるアセットも参照した。Figma MCPではStarterプランの取得上限により最新フレームの画像を取得できなかった。

| フロー    | 成功経路のノードID                                                                                                          |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| A・初回   | 28-100 → 29-683 → 36-778 → 38-898 → 43-1681 → 43-1745 → 43-1815 → 38-1056 → 52-5984 → 43-1966 → 66-8363 → 43-1269 → 38-1026 |
| B・修了後 | 38-1026 → 43-1494 → 66-7554 → 43-1903 → 66-8272 → 66-7869 → 66-10524 → 38-1026                                              |

初回と修了後の両方で、描画の成功演出を描画面の上で再生してから完成カードを開く。初回は所定のタップで進み、課題タイトル表示後だけ3秒で描画へ進む。修了後は、スケッチ準備と課題タイトルを自動で進める。修了後のホームは撮影画面。認識できない写真は写真確認で動物名を手動選択できる。公開用の動作と研究用テストサーバーの自動送信設定は [gdrive-share-setup.md](gdrive-share-setup.md) を参照。

## 承認済みの削除と追加確認

公開用ビルドは本体を1つにまとめる。11月21日に一般向けの追加機能を外す承認を受けた。下表の「個別判断」以外は画面から外す。承認前の機能はGit履歴にあり、端末の保存領域は削除しない。

| 区分             | 現在の候補                                                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| クイズ・継続要素 | クイズ、えさやりクイズ、親子クイズ、動物ビンゴ、特徴バッジ、月替わりチャレンジ                                                                                     |
| おでかけ・読み物 | おうちレポート、自由研究ポスター、ミニ絵本、ピツネのお部屋、思い出マップ、飼育員さんメモ、My Dayプラン、観察コース、ライブカメラリンク、昼・夜の切り替え、季節表示 |
| カード・画像     | 声メモ、ぬりえ・タイムラプスの書き出し、変身フォトフレーム、アルバムの追加エクスポート                                                                             |
| 管理・リンク     | 兄弟プロフィール、QRスキャン、課題ディープリンク、カード・ログのCSV書き出し、保存診断、観察前後の気づき比較                                                        |
| 個別判断         | 大学研究用のStudyControlsと2回描画、ノートのバックアップ・復元、ドパガキの演出、描画の塗りつぶし・色数・ズーム                                                     |

ふりがな、絵の自動送信は維持。観察前後の気づき比較や研究用CSVなど、研究計画に必要なものは一般ユーザー向けの整理と分けて判断する。

## 第3弾の照合

Figma MCPのStarter上限が続いていたため、公開閲覧できるFigmaの現行キャンバスで次のフレームを確認した。現行の書体とボタンラベルを使用し、既存の書き出しアセットを再利用した。

| 照合対象                                   | Figmaのフレーム               |
| ------------------------------------------ | ----------------------------- |
| 半円の地面・進行ドット                     | 29-683、36-778、38-898        |
| 写真保存のチェック・修正・撮り直し         | 66-7554、66-7604              |
| 完成前の演出・オレンジの完成カード         | 66-10524 と左隣の演出フレーム |
| ギャラリーのヘッダー・固定切替・カード詳細 | 63-6390 と右隣のカード詳細    |
| 課題タイトルと描画の操作                   | 66-8272、66-7869、66-8070     |

マイギャラリーの撮影写真を開き、共有から「写真を端末に保存」を選ぶと、対応ブラウザではOSの共有画面が開く。端末側で画像を保存する。ファイル共有に対応しないブラウザでは写真をダウンロードする。見本写真は撮影写真の書き出しの対象外。
