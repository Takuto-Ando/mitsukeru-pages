# ズーケッチ Figma v2 の照合と削除候補

## 照合した資料

Figma MCPはStarterの取得上限に達した。手元の `ズーケッチ.fig`（11月20日書き出し）にはページ名 `Page 1` と開始点 `初期画面` があり、画面間のクリック接続も含まれる。ブラウザで現行Figmaの「プロトタイプ1」を開き、画面名を照合した。インタラクティブ再生はログインが必要だったため、遷移の詳細は書き出し内の接続を参照した。指定された画面順の別紙とは、入手後に照合する。

| フロー | 書き出しで確認した主な接続 |
| --- | --- |
| 初回 | 初期画面 → チュートリアル01〜03 → チュートリアル撮影 → 写真確認 → ピツネに見せる → チュートリアル04 → スケッチ → 成功 → チュートリアル05 → 通常撮影 |
| 修了後 | 通常撮影 → 写真確認 → 難易度選択 → スケッチ → 成功 → 通常撮影。撮影からギャラリーを開き、写真・スケッチの切り替えと撮影への復帰ができる。 |

書き出しに複数の撮影・写真確認・描画フレームがある。撮影し直しとスケッチし直しの接続は書き出しに存在するが、v2ではチュートリアル内の後戻り禁止を優先する。描画が曖昧なときはチュートリアルの描画画面にとどまってヒントを表示する。通常フローでは撮り直しと描き直しができる。

## 承認済みの削除と追加確認

公開用ビルドは本体を1つにまとめる。11月21日に一般向けの追加機能を外す承認を受けた。下表の「個別判断」以外は画面から外す。承認前の機能はGit履歴にあり、端末の保存領域は削除しない。

| 区分 | 現在の候補 |
| --- | --- |
| クイズ・継続要素 | クイズ、えさやりクイズ、親子クイズ、動物ビンゴ、特徴バッジ、月替わりチャレンジ |
| おでかけ・読み物 | おうちレポート、自由研究ポスター、ミニ絵本、ピツネのお部屋、思い出マップ、飼育員さんメモ、My Dayプラン、観察コース、ライブカメラリンク、昼・夜の切り替え、季節表示 |
| カード・画像 | 声メモ、ぬりえ・タイムラプスの書き出し、変身フォトフレーム、アルバムの追加エクスポート |
| 管理・リンク | 兄弟プロフィール、QRスキャン、課題ディープリンク、カード・ログのCSV書き出し、保存診断、観察前後の気づき比較 |
| 個別判断 | 大学研究用のStudyControlsと2回描画、ノートのバックアップ・復元、ドパガキの演出、描画の塗りつぶし・色数・ズーム |

ふりがな、絵の自動送信は維持。観察前後の気づき比較や研究用CSVなど、研究計画に必要なものは一般ユーザー向けの整理と分けて判断する。
