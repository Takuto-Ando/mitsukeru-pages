# シャッター前の認識を録画で比較する

2026-11-26、Chromium 156、MacBook Air M2、画面幅390 × 高さ844。各録画の同じ先頭11.5秒をカメラ映像として再生し、実際のYOLOXとBioCLIPの結果でピツネのセリフが変わる時刻を記録した。BioCLIPはモデル準備済みの状態で比較した。録画は6種7本で、出典と同一ファイルの確認用ハッシュは [live-replay-fixtures.json](live-replay-fixtures.json) に記録した。

| 指標 | 変更前 `dd31bd0` | 変更後 |
| --- | ---: | ---: |
| 正しい名前が出ていた時間（候補と確定、全80.5秒） | 31.79秒（39.5%） | 32.31秒（40.1%） |
| 誤った名前が出ていた時間 | 18.33秒（22.8%） | 14.11秒（17.5%） |
| 正しい「かも！」を表示した回数 | 0 | 5 |
| 誤った「かも！」を表示した回数 | 0 | 6 |
| 正しい「がいるよ！」を表示した回数 | 5 | 3 |
| 誤った「がいるよ！」を表示した回数 | 5 | 1 |

同じ表示が続く時間と、表示に切り替わった回数を別々に集計した。レッサーパンダは変更後に1.93秒で候補、2.79秒で確定した（従来の確定2.73秒）。アジアゾウではロバの誤確定がなくなり、正しい候補を計10.42秒表示した。野生のカバはゾウと誤って断定することはなくなったが、今回の再生では正しい名前を出せなかった。柵越しのカバに正しい名前が出た回はない。ワオキツネザルをヤギ・ヒツジとする誤認は残った。録画再生でも、推論が完了する時刻によってサンプリングするフレームは変わる。30種全体やスマートフォン実機の評価は別途必要。

### 撮影中の判定条件

- 先に候補を表示する条件はBioCLIPの候補スコア0.60以上かつ2位との差0.07以上。枠内だけの場合はBioCLIP自身も高確度とする場合に表示する。
- 同じ名前を支持する読み取りの採用条件はスコア0.52以上かつ2位との差0.05以上。枠内の同じ切り出しが弱い確度で一致した場合は、全体など別の領域からの裏付けが必要。別の強い判定があれば、弱い一致では確定しない。
- キリン・ゾウは白枠とBioCLIPの高確度の判定が一致すれば、白枠スコア0.60以上で確定できる。白枠だけで名前が出る場合は「かも！」として扱い、撮影後に確定名として引き継がない。

## 再計測

1. マニフェストの `original` から録画を取得する。取得元のクレジットと利用条件は `source` を確認する。次の変換で `<id>.mp4` にし、マニフェストと同じフォルダに置く。ハッシュが異なる環境では、同じ変換済み動画を両方のビルドに使い、マニフェストのハッシュも再計算する。
2. 比較する2つの版をルートのベースパスでビルドする。BioCLIPのONNXは `src/recognition/bioclip-model.json` の固定リビジョンから取得し、両方の計測に同じファイルを指定する。
3. 片方ずつ下のコマンドを使う。JSONには正誤の回数と時間に加えて、白枠と分類Workerの応答を残す。

```sh
ffmpeg -i ORIGINAL -t 18 -vf 'scale=540:675:force_original_aspect_ratio=decrease:force_divisible_by=2,pad=540:676:(ow-iw)/2:(oh-ih)/2:color=0x7b7568,fps=15' -an -c:v libx264 -pix_fmt yuv420p -crf 20 -movflags +faststart ID.mp4

node tests/recognition/bench-live-replay.mjs DIST VIDEO_MANIFEST.json BIOCLIP.onnx REPORT.json
```
